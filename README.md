# 🩺 First Aid Intelligent System

An intelligent system designed to assist in real-time medical emergencies using **deep learning** and a full-stack architecture.  
The system identifies emergency situations from **text and images** and provides step-by-step first aid guidance — even offline.

---

## ⚠️ Prerequisites
Before cloning this repository, make sure **Git LFS** (Large File Storage) is installed, as model files are stored via LFS.  
Additional requirements and dependencies will be added in a future update.

[Install Git LFS](https://git-lfs.com/) and run:

```bash
git lfs install
```

---

## ✨ Features

- Text-based emergency detection using an LSTM NLP model (TensorFlow)
- Image-based emergency detection using a Faster R-CNN computer vision model (PyTorch)
- Severity evaluation to determine if ambulance intervention is required
- Offline support for emergency instructions (text, images, videos)
- SMS alerts with live location in critical cases
- Interactive chat interface for step-by-step guidance

---

## 🛠 Tech Stack

- **Frontend:** React.js
- **Backend:** Python (FastAPI)
- **AI Models:**
  - LSTM (NLP) – TensorFlow
  - Faster R-CNN (Computer Vision) – PyTorch
- **Database:** SQLite
- **Voice Recognition:** VOSK
